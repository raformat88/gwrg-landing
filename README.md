# GWRG (Global Warfare Recruitment Group)

Адаптивный лендинг для игрового фан-проекта Call of Duty (маркетплейс кланов и игроков).

## Структура проекта
- `index.html` — Главная страница
- `content.json` — Все изменяемые тексты, заголовки, списки (для редактирования через Decap CMS)
- `css/style.css` — Стили (милитари-тема, тёмный графит, сигнал-оранжевый акцент)
- `js/app.js` — Логика загрузки данных через `fetch('content.json')`, переключение языков (RU/EN)
- `admin/config.yml` — Конфигурация для Decap CMS

## Запуск локально
Для корректной работы `fetch()` запустите локальный сервер, например:
```bash
npx serve
# или с помощью python
python3 -m http.server 8000
```
